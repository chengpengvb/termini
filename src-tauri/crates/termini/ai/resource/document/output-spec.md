[Markdown 结构约定] 版式（字体/表格边框/代码块底色/页边距）由模板自动套用，不用在 Markdown 里控制；只需守住结构：
1. 标题从 # 开始逐级递进，不跳级。
2. 表格用管道表：表头行 + | --- | 分隔行 + 数据行，每行竖线数一致；单元格内不换行、不放列表；超过 8 列拆表。
3. 图片写 ![说明](绝对路径或 https 链接)；相对路径只在传了 source 时才能解析。
4. 不写裸 HTML（<table>/<div>/<span style> 会被丢弃）；<br> 会被自动替换成换行。
5. 代码块用三反引号并标语言；行内代码用单反引号。
6. 分页独占一行写 \newpage。
7. 封面、页眉页脚、分栏、指定字体字号不是 Markdown 能力，改用 script_run（python-docx / docx / pptxgenjs）。
8. 内容必须是可交付成品：开头有标题和摘要或结论，中间按节展开，数据用表格，不要无标题流水账。
